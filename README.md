# ZenFox

Zen-style workspaces for Firefox: a vertical sidebar with Essentials, pinned tabs and folders per workspace, a command palette, containers per workspace, Recently closed with Undo, and automatic tab sleep.

**Install:** [ZenFox on Firefox Add-ons](https://addons.mozilla.org/firefox/search/?q=ZenFox)

![ZenFox sidebar](screenshot.png)

## Support

This repository is for **bug reports and feature requests**. The extension's code is not published here.

- 🐞 [Report a bug](../../issues/new?template=bug_report.yml)
- 💡 [Suggest a feature](../../issues/new?template=feature_request.yml)

Before opening an issue, please check whether someone has already reported it in [open issues](../../issues).

## Privacy

ZenFox has no servers, accounts, analytics or tracking. Everything stays in your Firefox profile. Please don't paste private URLs or personal data into issues.
